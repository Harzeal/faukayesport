# FAUKAY E-SPORT — Real-Time CyberIndo Billing Monitor

Website monitoring status PC & sisa waktu billing **CyberIndo** secara *real-time* untuk warnet **Faukay E-Sport**.

## Kapasitas Arena
- **Zona VVIP (18 Unit)**: `VVIP 01` – `VVIP 18`
- **Zona VIP (28 Unit)**: `VIP 07` – `VIP 36` (2 nomor yang tidak dipakai dapat diatur langsung di website)

## Menjalankan Website Secara Lokal
```bash
npm install
npm run dev
```
Buka `http://localhost:3000`.
